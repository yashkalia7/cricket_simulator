# Watch notes

Raw observations from real matches. This file is the input to Phase 2 (§11) and
it is deliberately empty until then.

**The rules are not written by writing what sounds right. That reproduces
commentary slop in TypeScript.** The rules come from grouping what is written
here.

## Method (§11)

1. Open T20 matches. Skip to the 16th over.
2. Pause before each ball. Write three lines.
3. Do 100 balls — roughly an hour per match with pausing, so 3–4 matches, one
   weekend.
4. Group them. The same 6–7 situations recur. **Those clusters are the rules,
   not the reverse.**
5. Take the clusters, not the deliveries, to a coach: *"I saw three different
   balls in this situation. When is each right?"* That question produces the
   `unless` field.

Target 25–30 rules, not 100.

## Format

```
SITUATION: 18.4 | 22 off 8 | 3 down | set batter 34(19) | off-spinner | long-on + long-off back
BOWLED:    wide yorker, missed, low full toss
RESULT:    four through cover
```

Write `SITUATION` *before* seeing the ball. If you write it after, you are
recording a justification, not an observation.
